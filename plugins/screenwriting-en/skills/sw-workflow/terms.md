# Terminology Anchor Table

This table is the **cross-language infrastructure** of this skill set: the original skill bodies were written in Chinese, while the output language is chosen by the person asking. Terminology must not be improvised anew on every occasion.

**Why "anchoring" rather than "translation":** most of the terms in this table **were English in the first place** — *log line*, *act out*, *beat sheet*, *showrunner*, and *staff writer* are all original English terms. Chinese books render them with calques such as "计程绳" (jìchéng shéng), "出幕" (chūmù), "节拍表" (jiépāi biǎo), "剧目管理人" (jùmù guǎnlǐrén), and "试用编剧" (shìyòng biānjù), and different translators choose different renderings. Mapping the Chinese expressions back to the English originals is therefore not translation but **restoration**. This column serves every language at once: Japanese, French, and Korean screenwriters also use *act out*, *logline*, and *pitch* in professional contexts, so anchoring to the original is more useful than inventing a new term for them.

## Usage Rules (agent execution)

1. **Output language = the language of the question.** Answer in the language the user asks in; the Chinese skill bodies do not dictate the response language.
2. **Anchor terms back.** When outputting in a language other than Chinese, use the **English original in the first column** for every concept listed in this table. Do not translate "进展纠葛" (jìnzhǎn jiūgé) as *progressive entanglement* on your own; its original term is *progressive complications*.
3. **When outputting in Chinese,** use the second column. If the context could be ambiguous (especially the multiply overloaded words "脚本" (jiǎoběn), "大纲" (dàgāng), and "梗概" (gěnggài)), add the English original in parentheses.
4. **The terms in Sections 5 and 6 have no English equivalent.** In every language, **keep the original term and add a one-line explanation**; do not force an equivalent. Write `戏眼 (xìyǎn — the one-line core attraction of an episode)`, `ト書き (tosho — the action line of a Japanese script)`.
5. **For concepts not in this table,** follow the same principle: first determine which language the original term comes from, anchor to that original, then add a one-line explanation. Do not silently invent a translation.

## 7. Chinese Opera Terms (keep the original term + explanation)

The two Chinese opera systems and their units have no English equivalents. In every language, keep the original term and add an explanation.

| Original term | Meaning |
|---|---|
| 板腔体 (bǎnqiāngtǐ) | The *banqiang* system: a system built on paired seven- or ten-character lines and organized into arias by metrical pattern (Peking opera, Henan opera, Yue opera, Qinqiang, Pingju, Shanghai opera) |
| 曲牌体 (qǔpáitǐ) | The *qupai* system: words are filled into fixed tune patterns with prescribed character counts, line shapes, and tonal patterns; tunes are joined into suites (Yuan *zaju*, Ming–Qing *chuanqi*, Kunqu) |
| 板式 (bǎnshì) | The rhythmic pattern of a banqiang aria (导板／慢板／原板／快板／散板, etc.), which determines the line length and emotional color of a passage |
| 韵辙 (yùnzhé) | The rhyme categories used for aria lyrics; Peking opera uses the thirteen rhyme categories (十三辙), Henan opera uses Zhongzhou rhyme |
| 曲牌 (qǔpái) | A tune unit with a fixed metrical pattern in the qupai system, into which words are filled |
| 宫调 (gōngdiào) | The modal system to which a qupai belongs; in *zaju*, one act uses one mode |
| 填词 (tiáncí) | The qupai-system method of writing lyrics: filling words according to the metrical pattern of a tune |
| 折 / 出 / 场 (zhé / chū / chǎng) | The unit of *zaju* is the 折 (four 折 plus one 楔子); of *chuanqi*, the 出; of banqiang opera, the 场 |
| 一人主唱 (yīrén zhǔchàng) | The rule of Yuan *zaju*: in each act only the 正末 or 正旦 sings from beginning to end |
| 行当 (hángdang) | Role types such as 生, 旦, 净, and 丑; they determine the writing before character psychology does |
| 程式 (chéngshì) | Fixed performance and textual conventions: self-introduction, entrance poem, exit poem, aside, and so on |
| 宾白 (bīnbái) | Spoken dialogue in Chinese opera, as opposed to song |
| 科介 (kējiè) | Stage-action cues in the script |
| 唱念做打 (chàng niàn zuò dǎ) | The four skills of Chinese opera performance; the playwright must allocate their proportions within a scene |
| 重场戏 (zhòngchǎngxì) | The scene with the greatest value reversal in the whole play; arias should be concentrated there |
| 上句 / 下句（上韵 / 下韵） (shàngjù / xiàjù, shàngyùn / xiàyùn) | The smallest couplet unit of banqiang lyrics; the second line must rhyme, the first may or may not. **Henan-opera sources call them 上韵／下韵, with the same meaning** |
| 垛句 (duǒjù) | A string of three- or four-character short lines inserted outside the paired-line structure, used only in the metrical section and only in the second-line position, to accelerate and intensify |
| 衬字 (chènzì) | Words added beyond the character count prescribed by a qupai or banshi pattern; qupai-system padding follows rules, banqiang padding is freer |
| 扫头 (sǎotóu) | A supplementary line at the end of a Peking-opera aria; the only legitimate exit that allows an aria to have an odd number of lines |
| 务头 (wùtóu) | The most important and most beautiful line or few characters in a qupai passage; fix the 务头 first, then fill the rest. The banqiang equivalent is the "重点句" (zhòngdiǎnjù — key line) |
| 前腔 / 换头 / 幺篇 (qiánqiāng / huàntóu / yāopiān) | Three notations for reusing the same qupai: **前腔 and 换头 belong to Southern drama** (换头 changes the opening line's pattern), **幺篇 belongs to Northern drama**; "if you see 前腔, it must be Southern drama" |
| 隔尾 (géwěi) | A sectional tune within the Nanlü suite; not the coda |
| 楔子 (xiēzi) | A short section outside the four acts of Yuan *zaju*, usually at the beginning, with its own rhyme |
| 题目正名 (tímù zhèngmíng) | The two- or four-line summary of the whole play at the end of Yuan *zaju*, from which the play's title is taken |
| 副末开场 (fùmò kāichǎng) | The *chuanqi* convention in which the 副末 enters in the first 出 to state the author's intent and the story; *The Peach Blossom Fan* expands it into a through-line |
| 集唐下场诗 (jítáng xiàchǎngshī) | The *chuanqi* convention of ending each 出 with an exit poem assembled from Tang-dynasty lines, which both closes the current 出 and hints at the next |
| 合头 / 合 (hétóu / hé) | The section at the end of a Southern tune sung by all performers together |
| 帮腔 (bāngqiāng) | A device in high-pitched opera (such as Sichuan opera) in which offstage voices answer or comment; written into the script as an independent "role." Banqiang opera has no equivalent |
| 幕内唱 / 内唱 (mùnèichàng / nèichàng) | A line or passage sung offstage before the character enters, usually in 导板 (dǎobǎn) |
| 换科 (huànkē) | A specialized *zaju* stage cue marking a "swap in full view" (bait-and-switch) action |
| 製曲 / 譜曲 / 度曲 (zhìqǔ / pǔqǔ / dùqǔ) | The three divisions of labor in the qupai system: the playwright fills in words / the composer sets the tune / the performer sings. The playwright is responsible only for 製曲 |
| 曲谱 / 宫谱 (qǔpǔ / gōngpǔ) | **曲谱** collects aria texts and metrical rules (such as *Jiugong Dacheng* and *Nashuying*); **宫谱** lists only the mode to which each qupai belongs. Use the former to check metrical rules |
| 排场 (páichǎng) | The arrangement of entrances, exits, and hot/cold contrast across a play (Wang Jilie); a structural layer parallel to, and distinct from, "剧情" (jùqíng — plot, the cycle of joy and sorrow, separation and reunion) |
